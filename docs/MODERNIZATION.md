# WAAMBAT modernization review

Work is isolated to `Ravonus/waambat.com`, branch `feat/gallery-admin-modernization`, draft PR https://github.com/Ravonus/waambat.com/pull/1. The initial repository was a T3 scaffold with an unused Drizzle example; the original live site is Squarespace. No KEEL repository, Mac, VPS, public production, DNS or paid service was modified.

## Portfolio and performance

Next 16.4, React 19, Tailwind 4 and current ESLint tooling preserve the researched black/pink/purple presentation, centered branding, eight navigation labels, 23 paintings and original media URLs. Instagram now has its requested local gallery, six original post destinations and 32 recovered original public-site image references. Editable article/archive routes retain the recovered mechanics, press, bio/interview and contact content. The art archive retains 25 original still references and previous/next/info/number/thumbnail navigation.

Original NFTs and Ordinal A/B/C destinations remain. LUX/OK Algo uses verified Satflow and Pink Paper links and an official still. Kismet Twist is presented beside LUX in a prominent collection row before the preserved original Ordinals. Its consent-only preview uses verified Kismet Twist #100 inscription metadata and the original on-chain preview. The exact user-supplied Gamma artwork URL is also retained; its unavailable title/preview metadata is not invented. Unverified first/largest, current supply and pricing claims are omitted; no generated replacement artwork or unreviewed trailer is inserted.

The 23 original source PNGs total 35,475,401 bytes. Responsive stills total 1,074,172 bytes at 480 pixels and 3,460,340 bytes at 960 pixels (97% / 90% smaller than the source PNG total). This is an asset comparison, not measured live video bandwidth savings. Original sources remain intact.

Video URLs attach near the viewport, pause offscreen/background and remain attached once loaded to avoid deliberate refetch on scrolling back. Responsive posters load lazily; optional mobile video URLs preserve artist control over alternate sources. Reduced motion and save-data require explicit playback. Desktop/mobile Chromium checks decode a generated MP4 through controlled fixtures; live original provider transport is blocked by this environment. No claim of actual remote playback is made.

Navigation uses native Next links/prefetch and browser history with immediate non-blocking datamosh-style bands. Pending hints and loading/error views reflect real route state. Pink gradient cursor decoration uses fine-pointer capability, never intercepts clicks, preserves the native cursor/text affordances, hides in editing fields and on touch, and stops animating with reduced motion. Artwork is not altered by the effect.

## Content studio and persistence

All reads/writes, drafts, uploads and captures enforce server authorization. Existing GitHub identity supports stable numeric allowlists; Google artist identity requires a verified exact `waambat@gmail.com` allowlist match. Backup `admin` login uses actual isolated Postgres in tests, random private secrets, scrypt N=131072/r=8/p=1, rate locks and version revocation. Shared rate/admission control bounds unknown, locked and disabled-account KDF work, with separate password/session pools and no transaction held during hashing. No hardcoded account or password, registration endpoint or fake persistence exists. Deployed admin remains disabled until approved credentials are configured.

Create pages with existing-design article, gallery or archive templates. Add text/link/image/provider blocks, sections and artwork; edit navigation labels/destinations/order; archive and restore content. Slugs are immutable in the editor and existing-page removal/rename is rejected server-side. Shared strict schemas validate unique IDs/routes, reserved slugs, internal references, HTTPS media and plain text. Providers recognized: original Imgur/direct MP4, YouTube, Vimeo and Instagram. Fixed player URLs replace arbitrary HTML; consent and original-source links provide an honest unavailable-content fallback. Instagram posts/reels support optional title, cover, description, ordering and featured display; highlights stay links when no supported embed exists. No scraping or private-media downloading occurs.

GitHub's `src/content/site.json` is the single published-content source. Private drafts are commits on the approved draft branch; publish changes only that content file on the configured review deployment branch with expected-parent checks and non-forced updates. Public SSR uses the deployed JSON without runtime Git or database access. Optional approved Netlify Database supplies admin identity through the official branch-aware SDK; working Git drafts are retained. See [NETLIFY-SETUP.md](NETLIFY-SETUP.md) for precise remaining configuration and migration/backup safeguards.

Uncertain save/publish responses reconcile remote commits without automatic write replay. Draft edits survive network failures and stale revisions. Upload cancellation, timeouts, byte signatures/MIME, content hashes, private media and range requests are exercised. UI and server archives preserve originals; previous commits remain recoverable. Outgoing email settings support Gmail/custom SMTP, actual verified senders and server secrets; the preview captures MIME without delivery. No message or invite was sent.

## Evidence and limits

Evidence files record unit/Git tests, browser desktop/mobile playback and studio workflows, isolated password authentication/Instagram/email capture/mixed-page composition, and compiled public preview/privacy checks. Netlify's Git integration reports the separately tested public-access checkpoint ready at https://deploy-preview-1--waambat.netlify.app. This environment's remote browser proxy blocks rendered verification; local screenshots are not live-site baseline screenshots.

Complete visual fidelity remains blocked on the promised original HTML/CSS/media archive: `/waambat`, `/lindsay-scoggins`, `/art` and `/nfts-copy` could not be fetched; original 23 archive player URLs, some marketplace destinations, the licensed Europa/Amboy loader remain unresolved. These routes are schema-compatible but absent content is not replaced with invented pages or redirects. The fonts are named in CSS but licensed font bytes/loader were not guessed. No original media or branding was removed.

Real Google/GitHub OAuth, GitHub App runtime writes, Netlify Database/Blobs and provider playback require approved connections and remote integration QA. Auth.js v5 is still beta; Next lint plugins declare ESLint <=9 peer ranges despite passing current lint. Keep the PR draft and public production unchanged until fidelity and runtime acceptance are complete.
